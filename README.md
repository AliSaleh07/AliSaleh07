## 📌 About Me

I am a **Software Engineer** specializing in defensive application security, systems programming, and backend architecture. My technical work spans across the engineering lifecycle—from writing low-level, multi-threaded network scanners in modern **C++17**, to architecting secure REST services in **Node.js/TypeScript** and **Python**, to creating real-time vulnerability dashboards in **React**.

Rather than treating security as an afterthought, I build software that is secure by default: incorporating strict cryptographic primitives, zero-trust tenant boundaries, token-bucket rate limiting, and automated static container auditing into core workflows.

### 1. [NetProbe](https://github.com/AliSaleh07/netprobe)
*High-Performance Network Diagnostics & Defensive Security Scanner in Modern C++17*
- **Technology**: **C++17**, CMake, POSIX / Winsock Sockets, Multi-threading.
- **Engineering**: Asynchronous non-blocking TCP socket polling (`select()`), worker thread pool with controlled concurrency, and token-bucket rate limiting.
- **Defensive Safeguards**: Validation layer blocks accidental broadcast/multicast scanning and enforces `/24` safe CIDR limits.
- **Banner Fingerprinting**: Service identification and banner grabbing for HTTP, SSH, SMTP, and Redis protocols.

### 2. [Sentinel API](https://github.com/AliSaleh07/sentinel-api)
*Defensive AppSec Findings Management & Vulnerability Ingestion REST API*
- **Technology**: **TypeScript**, **Node.js**, Express, Zod, Helmet, Winston, Vitest.
- **Defensive Controls**: Role-Based Access Control (Analyst vs Admin), dual-tier IP rate limiting (10 attempts/15m on auth routes to prevent brute-force attacks).
- **Zero-Trust Validation**: Strict runtime schema parsing via Zod before payload reaches controllers or storage.
- **Production Container**: Hardened multi-stage Docker build running under an unprivileged `USER node`.

### 3. [SecOps Dashboard](https://github.com/AliSaleh07/secops-dashboard)
*Cybersecurity Operations & Vulnerability Triage Interface*
- **Technology**: **React 19**, **TypeScript**, Vite, Lucide Icons, Vitest.
- **Interface**: High-contrast cybersecurity dark theme with real-time vulnerability search, severity pills, and CVE inspection.
- **Hybrid Data Pipeline**: Live synchronization with Sentinel API with an instant graceful fallback to a structured sample dataset.
- **Interactive Triage**: In-place status transitions (`OPEN` $\leftrightarrow$ `RESOLVED`) and zero-dependency SVG distribution charts.

### 4. [TaskForge](https://github.com/AliSaleh07/TaskForge)
*Defensive Task Management REST API with Zero-Trust Multi-Tenancy*
- **Technology**: **Python 3**, FastAPI, SQLAlchemy, Pydantic v2, Pytest.
- **Security Focus**: Cryptographic password hashing, JWT sessions, strict IDOR isolation, and security headers.

### 5. [compose-scout](https://github.com/AliSaleh07/compose-scout)
*Docker Compose Static AST Security Auditing & Misconfiguration Linter*
- **Technology**: **Python 3**, PyYAML (SafeLoader), Argparse, Pytest.
- **Security Focus**: AST linting detecting privileged containers, root execution, docker socket mounts, and unbounded ports.

### 6. [secret-sentry](https://github.com/AliSaleh07/secret-sentry)
*Zero-Exfiltration Local Secret Scanner & Shannon Entropy Detector*
- **Technology**: **Python 3**, Shannon Entropy Engine, Regex Heuristics, Pytest.
- **Security Focus**: 100% offline, zero-exfiltration credential detection with automated redaction masking.
