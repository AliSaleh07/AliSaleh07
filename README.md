## 📌 About Me

I am a **Software Engineer** focused on **Cybersecurity, Application Security, Penetration Testing, Backend Development, and Systems Engineering**. My engineering philosophy is built around a *Security by Default* doctrine: baking rigorous authentication boundaries, least-privilege permissions, zero-trust multi-tenancy, and automated vulnerability inspection directly into the software architecture.

My technical work spans the entire defensive development lifecycle:
- Writing low-level, high-concurrency network scanners in modern **C++17** utilizing asynchronous non-blocking sockets.
- Architecting hardened, type-safe REST APIs in **Node.js/TypeScript** and **Python (FastAPI)** with dual-tier rate limiting, RBAC, and Zod runtime schema validation.
- Engineering reactive, dark-mode vulnerability operations dashboards in **React 19** for real-time security triage.
- Conducting penetration testing, network traffic dissection with **Wireshark** and **tcpdump**, and web application auditing against the **OWASP Top 10**.

### 1. [NetProbe](https://github.com/AliSaleh07/netprobe)
*High-Performance Network Diagnostics & Defensive Security Scanner in Modern C++17*
- **Stack**: `C++17`, `CMake`, `POSIX / Winsock Sockets`, `Multi-threading`.
- **Engineering Highlights**: Asynchronous non-blocking TCP socket polling (`select()`), worker thread pool with controlled concurrency, and token-bucket rate limiting.
- **Safety Interceptors**: Built-in validation interceptors block accidental broadcast (`255.255.255.255`), multicast (`224.0.0.0/4`), and enforce safe CIDR limits.
- **Service Banner Fingerprinting**: Probes open ports to extract service banners for HTTP, SSH, SMTP, and Redis protocols with structured JSON reporting.
- **Automated Verification**: 7 comprehensive unit test suites passing; multi-compiler GitHub Actions CI workflow.

### 2. [Sentinel API](https://github.com/AliSaleh07/sentinel-api)
*Defensive Application Security Findings Ingestion & Triage REST Service*
[![Live API](https://img.shields.io/badge/Live_API-sentinel.salehsec.dev-00f5ff)](https://sentinel.salehsec.dev/)

- **Stack**: `TypeScript`, `Node.js`, `Express`, `Zod`, `Helmet`, `Winston`, `Vitest`.
- **Security Controls**: Role-Based Access Control (`role: analyst` vs `role: admin`), dual-tier IP rate limiting (10 attempts/15m on auth endpoints to prevent brute-force attacks).
- **Persistent Credential Storage**: Persistent atomic disk storage with runtime password rotation and immediate JWT token revocation.
- **Zero-Trust Validation**: Strict runtime schema parsing via Zod before payloads touch controllers or storage layers.
- **Production Container**: Hardened multi-stage Docker build running under an unprivileged `USER node`.
- **Automated Verification**: 34 integration test suites covering RBAC, auth, input validation, and metrics; passing CI on Node 20 & 22.

### 3. [SecOps Dashboard](https://github.com/AliSaleh07/secops-dashboard)
*Cybersecurity Operations & Vulnerability Triage Interface*
[![Live Demo](https://img.shields.io/badge/Live_Demo-dashboard.salehsec.dev-00f5ff)](https://dashboard.salehsec.dev/)

- **Stack**: `React 19`, `TypeScript`, `Vite`, `Lucide Icons`, `Vitest`.
- **Interface**: Cybersecurity dark theme with real-time multi-attribute vulnerability search, severity pills, and CVE inspection.
- **In-Memory Security**: Zero persistent credential storage (no tokens in localStorage/sessionStorage); interactive analyst authentication.
- **Interactive Triage**: In-place status transitions (`OPEN` $\leftrightarrow$ `RESOLVED`) and zero-dependency SVG distribution charts.
- **Automated Verification**: 10 component and service integration tests; passing CI on Node 20 & 22.

### 4. [TaskForge](https://github.com/AliSaleh07/TaskForge)
*Defensive Task Management REST API with Zero-Trust Multi-Tenancy*
[![Live API Docs](https://img.shields.io/badge/Live_API-taskforge.salehsec.dev-00f5ff)](https://taskforge.salehsec.dev/docs)
- **Stack**: `Python 3`, `FastAPI`, `SQLAlchemy`, `Pydantic v2`, `Pytest`.
- **Security Focus**: Zero-trust tenant isolation preventing Insecure Direct Object References (IDOR), cryptographic password hashing (Argon2 / PBKDF2), and strict security response headers.
- **Automated Verification**: 23 test assertions passing across 5 suites; green GitHub Actions CI matrix.

### 5. [compose-scout](https://github.com/AliSaleh07/compose-scout)
*Docker Compose Static AST Security Auditing & Misconfiguration Linter*
- **Stack**: `Python 3`, `PyYAML (SafeLoader)`, `Argparse`, `Pytest`.
- **Security Focus**: Static AST inspection detecting privileged container execution, root execution, docker socket mounts, and exposed database ports.
- **Automated Verification**: 14 test suites passing; zero unhandled deserialization vulnerabilities.

### 6. [secret-sentry](https://github.com/AliSaleh07/secret-sentry)
*Zero-Exfiltration Local Secret Scanner & Shannon Entropy Detector*
- **Stack**: `Python 3`, `Shannon Entropy Engine`, `Regex Heuristics`, `Pytest`.
- **Security Focus**: 100% offline, zero-exfiltration credential detection with automatic redaction masking and OOM-safe file size limits.
- **Automated Verification**: 17 test suites passing; green GitHub Actions CI.

### 7. [authlog-lens](https://github.com/AliSaleh07/authlog-lens)
*Defensive Linux Authentication Log Analyzer & Intrusion Detector*
- **Stack**: `Python 3`, `Syslog Engine (RFC 3164 & ISO-8601)`, `Pytest`.
- **Security Focus**: Detects SSH brute-force bursts, credential stuffing across multiple user accounts, and outputs structured SIEM JSON.
- **Automated Verification**: 10 test suites passing.

### 8. [openapi-smoke](https://github.com/AliSaleh07/openapi-smoke)
*Automated OpenAPI Specification Validator & Smoke-Testing Engine*
